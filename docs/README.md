# Документация domofomka

Статическая русскоязычная вики: Astro/Starlight и интерактивные схемы LikeC4.
Исходники статей находятся в `src/content/docs`, модель — в `architecture/*.c4`.
Исторические JSON/CSV-отчёты остаются в корне `docs`: их пути используют команды оценки.

Требуется Node.js 22.23.4 или новее. Из каталога `docs`:

```bash
npm ci
npm run dev
npm run build
npm run preview
```

`npm run build` проверяет модель, собирает HTML/CSS/JS в `dist` и ограничивает размер
результата 32 МиБ. CI собирает и сохраняет сайт отдельным артефактом. Node, npm,
LikeC4 и исходники вики не включаются в образы бота и API и не нужны на VDS.
Готовый `dist` можно раздавать любым статическим хостингом. Для подкаталога задайте
`DOCS_BASE_PATH=/domofomka`, для абсолютных ссылок — `DOCS_SITE_URL`.

После изменения процессов обновите соответствующие статьи и C4-модель, затем
выполните сборку. Данные пользователей, `.env`, дампы и адреса серверов в вики не публикуются.
