## Путь запроса

1. Сервис нормализует регистр, пробелы, сокращения и порядковые номера улиц.
   Отдельно извлекает местность, название улицы, дом, корпус, строение и подъезд.
2. Ключ ограниченного кеша включает запрос, параметры поиска и ревизию каталога.
3. PostgreSQL получает кандидатов улиц через `to_tsvector('simple', words)` и GIN.
   Сначала рассматриваются адреса с кодами. Точные B-tree ограничивают выбранные дома и варианты.
4. RapidFuzz помогает сопоставить опечатки. Числовые части дома и значимые ограничения
   названия проверяются отдельно: похожесть названий не заменяет точный корпус или букву.
5. Один подходящий адрес с кодами возвращается сразу; несколько требуют выбора.
   Распознанный дом без кодов получает результат `no_codes`, неизвестный адрес — `not_found`.

Геометка сначала превращается в адрес через DaData, затем проходит тот же поиск.
Обычный текст не отправляется в DaData и не расходует её запросы.

## Совместимый поиск v1

Если v2 не нашёл подходящий адрес или каталог временно недоступен, вызывается v1.
Он читает неизменённую исходную SQLite через индекс кандидатов либо исходный поиск.
Перед возвратом v2 проверяет результат v1 на соответствие ограничениям исходного запроса.
Другой корпус, строение, буква, местность или противоречащее название не допускаются ради выдачи кодов.

`no_codes` отличается от ошибки каталога: известному дому не подставляются коды соседнего.
Идентификатор выбранного дома позволяет получить его данные без повторного свободного поиска.

## Ответ пользователю

- Один подъезд — коды сразу, без лишнего нажатия.
- Несколько подъездов — кнопки выбора; большие наборы разделяются с учётом лимитов VK.
- Несколько адресов с кодами — список с отменой и возвратом к той же странице.
- Дома без кодов не заполняют список вариантов вместо имеющихся кодовых адресов.
- Неполный или неоднозначно исправленный адрес требует подтверждения пользователя.

## Данные и ограничения

Каталог PostgreSQL содержит связанные дома с кодами, подъезды, источники, варианты адресов
и происхождение исходных строк. Известные дома ГАР без кодов хранятся сжатыми наборами по улицам.
API читает опубликованную БД отдельной ролью без права записи. Версия схемы и ревизия проверяются.
Исходные XML, переписки и промежуточные базы находятся в `artifacts/` и не поставляются на VDS.

Кеш ограничен TTL, количеством записей и байтами; соединение с каталогом и SQL имеют дедлайны.
Настройки находятся в `.env.example`. Схема таблиц и индексов — в [БД](database.mdx),
словарь адресов — в [адресном языке](address-language.md), последовательность работы — в [процессах](processes.mdx).
