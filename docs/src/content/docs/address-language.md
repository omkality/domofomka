---
title: "Адресный язык и числительные"
---

Словарь и грамматика решают разные задачи. Данные русского языка находятся рядом
с реализацией соответствующей версии:

- `src/code_service/services/v1/russian.json` — неизменённый список типов улиц исходного поиска.
- `src/code_service/services/v2/russian.json` — основы порядковых числительных, десятки,
  сокращения городов, типы улиц, служебные слова и названия месяцев.

JSON читается один раз при импорте. Словари доступны коду только для чтения.
Это версионируемая часть алгоритма, а не настройка сервера в `.env`.
Грамматические правила в `services/v2/normalize.py` определяют роль числа: номер улицы,
дом, корпус, строение или подъезд. Их нельзя заменить общей подстановкой всех
слов, похожих на числа: так можно изменить название улицы либо потерять корпус.
Регулярные выражения грамматики остаются в коде и проверяются тестами.
