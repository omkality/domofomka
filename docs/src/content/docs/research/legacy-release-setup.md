## Первый переход с prod v1

Для первой установки используется `ops/bootstrap_ci.py --legacy-v1-baseline` с окружением `prod`.
Обычный режим ожидает уже работающий v2. Снимок v1 создаётся до изменения серверного `.env`;
исходники сверяются с опубликованным v1.5.6, секреты остаются на VDS в закрытом каталоге.
Откат `legacy-v1` доступен отдельным выбором в workflow и разрешён приёмником только для prod.
Входящий CI-релиз не может объявить себя старым runtime: этот признак имеет только снимок администратора.

Незавершённая очередь после отката на v1 блокирует новый переход до сверки доставок.
Подробный порядок и границы репетиции — в [плане первого выпуска](release-v2.md).
