### Проверка замены клиента на dev, 06.11.2026

Код замены HTTPX опубликован в `7c34e3d`, первая проверенная сборка dev — `f12e82b`.
В Linux CI прошли 300 тестов, одна проверка старого цикла событий пропущена; локально — 299 и два пропуска.
Отдельный интерпретатор проверяется настоящими локальными сокетами и несколькими циклами событий.
Общий дедлайн дополнительно проверен на теле ответа, зависшем после получения HTTP-заголовков.

На Германии все 62 HTTP-ответа совпали с принятым кандидатом каталога.
Прогон из 120 смешанных обращений к API дал p50 5,916 мс, p95 11,958 мс, максимум 180,289 мс.
Это небольшой ограниченный прогон, а не SLA доставки ответа VK.
Прямые обращения и переход после отказа прокси прошли для DaData и VK; сообщения не отправлялись.
Проверены настоящие вызовы внутреннего API из процессора бота: текст, геометка и выбранный дом.
Индексация и поиск HTTPX также проверены на двух искусственных документах локального OpenSearch;
временный индекс после проверки удалён.

Сравнение двух образов на одном VDS: прежний образ после успешного геокодирования завершился кодом 139,
образ с HTTPX — кодом 0. Точная причина сбоя прежнего нативного клиента не установлена;
успешный HTTP-ответ и штатное завершение процесса оцениваются отдельно.
Длительную проверку повторных внутренних запросов выполняют отдельно в ограниченном контейнере,
чтобы отследить RSS и чистое завершение при той же небольшой памяти.


Дополнительная проверка `500155a`/сборки `3cfadc9`: сертификаты загружаются один раз на процесс.
В Linux CI прошёл 301 тест, одна проверка старого цикла событий пропущена.
Контрольный прогон до переиспользования контекста: 120 запросов за 595 с, RSS 62,55 → 71,91 МиБ.
Повторная серия после изменения: 120 запросов за 11,91 с, RSS 63,72 → 63,74 МиБ без дальнейшего роста
после первых запросов. Обе серии выполнялись отдельным процессом с лимитом 128 МиБ и CPU 20%.
Интервалы различались, поэтому времена этих серий не являются сравнительным бенчмарком скорости.
OOM и перезапусков рабочих контейнеров не было; временные тестовые контейнеры удалены.
Это ограниченная проверка, а не гарантия поведения при любом количестве запросов.

Восстановление серверной копии очереди повторно проверено на Германии в отдельной временной БД.
Проверочная БД удалена, сохранены три поколения; последний дамп занимал около 90 КБ.
Из восстановленной копии бот не запускался, копий на ПК не создавалось.
