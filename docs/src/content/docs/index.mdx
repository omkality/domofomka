domofomka получает текст, геометку или нажатие кнопки из VK, ищет адрес и показывает
имеющиеся коды. Один подходящий подъезд открывается сразу; неоднозначный адрес
уточняется кнопками с отменой и возвратом к списку.

## Что работает сейчас

- **Бот VK** сохраняет события в inbox, а подготовленные отправки и редактирования — в outbox.
- **Сервис кодов** предоставляет HTTP API v1 и v2. v2 использует `tsvector`/GIN PostgreSQL,
  точные ограничения адреса и RapidFuzz для опечаток. Это лексический поиск, **не pgvector**.
- **PostgreSQL** хранит две отдельные БД: опубликованный каталог и рабочую очередь с диагностикой.
- **SQLite** остаётся источником v1 и проверяемым резервным поиском.
- **DaData** определяет адрес по координатам. Текстовый поиск не расходует её лимиты.
- **HTTP-прокси** необязателен. Ошибка подключения может переключить безопасный запрос на прямой маршрут.

Векторной БД, семантического поиска, RAG и распознавания голоса в текущей версии нет.
OpenSearch используется только отдельными командами сравнения, не рабочим окружением.
