# Сравнение настроек OpenSearch — 06.11.2026

Ниже сохранён исходный прогон. [Повтор после исправлений](#повтор-после-исправлений-нормализации) находится в конце.

## Что сравнивали

Через настоящий локальный OpenSearch выполнены шесть прогонов **одной и той же выборки из 4 000 элементов**.
В ней 2 528 предполагаемых исправлений запросов и 1 472 примера прежних ответов.
Примеры распределены по признакам ошибок: подъезды, порядковые номера, слитное написание, части номера дома.
Индекс содержит 1 077 597 документов улиц; окончательный дом и коды проверяются каталогом.
Каждый вариант с OpenSearch объединяет его кандидатов с результатами каталога.

Это сравнение конфигураций на предварительной разметке, а не доказательство точности.
Предполагаемые исправления не подтверждены пользователями. Прежний ответ бота тоже мог быть неверным.
Вся доступная выгруженная история прошла аудит; для этой матрицы используется выборка, а не все сообщения.
Корпус уже участвовал в разработке, поэтому независимой слепой проверкой он не является.

## Результат

«В ответе» — эталонный адрес выбран автоматически; «в выборе» — он присутствует среди вариантов с кодами.
Задержка измерена на ПК при шести процессах, без кэша API, DaData и доставки через VK.

| Вариант | Fuzziness / префикс / кандидаты | В ответе | В выборе | Всего сохранено | p50, мс | p95, мс |
|---|---|---:|---:|---:|---:|---:|
| Только каталог | — | 2376 | 450 | 2826 | 31,976 | 143,485 |
| Строже | 1 / 2 / 50 | 2397 | 451 | 2848 | 36,973 | 151,511 |
| Текущий | AUTO / 1 / 100 | 2407 | 451 | 2858 | 41,452 | 154,632 |
| Без обязательного префикса | AUTO / 0 / 100 | 2408 | 451 | 2859 | 43,751 | 157,469 |
| Больше кандидатов | AUTO / 0 / 200 | 2409 | 451 | 2860 | 45,101 | 160,964 |
| Два исправления | 2 / 1 / 100 | 2407 | 451 | 2858 | 41,189 | 157,584 |

Во всех вариантах сохранены 1 460 из 1 461 результата, которые на этой выборке находит нынешний v1;
автоматических ответов с другим адресом в этом подмножестве нет. Сетевых отказов индекса в этих прогонах не было.
Оставшийся спорный случай требует ручной проверки смысла адреса.
Этот показатель не оценивает правильность остальных автоматических ответов и не обещает отсутствие ошибок.

**Решение: оставить AUTO / 1 / 100.** Расширение даёт ещё два совпадения предварительной разметки,
но не улучшает сохранность прежних успешных ответов на выборке. Оснований объявлять его точнее пока нет.
На небольшом немецком VDS продолжает работать компактный каталог; OpenSearch сравнивается локально.

В выборке есть 255 запросов с подъездами, 186 с числовым номером улицы,
20 с порядковым номером словами, 233 со словами корпуса/строения и 126 со слитным написанием.
Эти категории пересекаются. Запрос с сокращением города всего один: выводы о качестве всех сокращений по нему делать нельзя.
Разбор «мск», «спб», «питер» и порядковых номеров дополнительно проверяется отдельными примерами в тестах.

## Где посмотреть настройки и повторить

- `src/search/engine.py`: `MAPPING` задаёт анализатор и поля; `search_body` строит запрос.
- `.env`: `OPENSEARCH_FUZZINESS`, `OPENSEARCH_PREFIX_LENGTH`, `SEARCH_CANDIDATE_LIMIT` управляют запросом API.
  После изменения нужен перезапуск API. Порог сходства и допустимая разница оценок задаются отдельно.
- `tools/benchmark_search.py`: фиксированная матрица, детерминированная выборка и проверка неизменности исходников между прогонами.

```bash
python -m tools.benchmark_search --workers 6
```

Нужны закрытый корпус `artifacts/private/audit`, каталог, исходная `codes.db` и работающий локальный OpenSearch.
Сводка и построчные результаты сохраняются в `artifacts/private/opensearch-matrix/` и не попадают в Git.
SHA-256 выборки: `500bd2bec1009f03f3a9a7eb97d2b3bb7b91d0946e4f84840cc30d3d3eb620a2`.

Для интерфейса индекса:

```bash
docker compose --env-file .env.dev -f compose.search.yml --profile ui up -d opensearch dashboards
```

На ПК доступны [документы индекса](http://localhost:15601/app/discover)
и [консоль запросов](http://localhost:15601/app/dev_tools).
В Discover выберите `domofomka-buildings`; это псевдоним текущего индекса, а не все старые сборки.
В Dev Tools можно выполнить:

```http
GET domofomka-buildings/_mapping
GET domofomka-buildings/_settings
```

В индексе нет переписок пользователей и самих кодов домофонов.
Локальные порты привязаны к loopback; отключённая в лаборатории авторизация не подходит для публикации в интернете.

Сохранность прежних успешных примеров во всех вариантах — 1 460 из 1 461; автоматических подмен в этом подмножестве нет.
Решение о настройке не изменилось: два дополнительных совпадения слабой разметки не доказывают улучшение точности.
Фоновая нагрузка на ПК менялась во время последовательных прогонов, поэтому их задержки нельзя использовать для выбора самого быстрого варианта.
